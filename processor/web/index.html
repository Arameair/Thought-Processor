Thought Processor

Sets up and diagnoses thinking. It does not think, and it does not grant permission.

Sign in to this Processor

Each time Processor starts it prints a one-time link in the window that started it. Open that link, or paste the code here.

The code is also saved in the profile at runtime/operator-code. It only unlocks this Processor's own diagnostic pages — it is not an Identity approval.

How the three parts fit together
  • Identity decides who is trusted and what is permitted.
  • Thought Processor (this page) helps you set things up and see what is really happening.
  • Thought Engine does the actual thinking.

Starting or attaching an Engine needs Identity's approval, and the part that does the starting must check that approval itself. Running is not the same as permission to receive observations — that is a second, separate approval.
